기본 설정

사이트 정보 및 공유/SEO 기본 정보를 설정합니다.

사이트 이름을 입력하세요.
PNG (권장 512×512)
ICO (권장 16×16)
권장 1200×630 / 최소 200×200 / PNG / 8MB 이하
모바일 HD 처리(50%) / PNG, JPG, GIF

상점/사이트 정보 설정

가입/주문 양식에 반영되므로 정확히 입력하세요.

사이트 푸터에는 자동 반영되지 않습니다(디자인 모드에서 편집).

기타 설정

운영 편의 옵션들입니다.

중요 기능 제약이 있으니 꼭 필요할 때만 사용하세요.
다국어 사이트에서 접속 언어에 맞춰 자동 이동합니다.
소유자/운영진 접속을 통계에서 제외합니다.
